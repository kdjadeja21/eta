# FE-002 — Klaus v2 design system (develop-v2)

## Summary

Presentation-only rewrite to the **paper ledger** design system. No backend/API/schema changes. `AddCashDialog` remains **out of IA** (file exists, not mounted).

## Design system

- **Tokens:** `app/globals.css` — paper/ink/rust palette, 8px radius, light default
- **Fonts:** Fraunces (display/money), IBM Plex Sans (UI), IBM Plex Mono (version hash only)
- **Charts:** `lib/chart-colors.ts` — ink opacity steps + rust accent (no Recharts rainbow)
